# Notes Manager

A command-line Notes Manager built with Bash scripting.

## Features

- Add new notes
- View all saved notes
- Search notes by keyword
- Highlight searched keywords
- Delete a specific keyword from notes
- Display remaining notes after deletion
- Case-insensitive search and deletion
- Menu-driven interface

## How to Run

Make the script executable:

chmod +x notes_manager.sh

Run the application:

./notes_manager.sh
