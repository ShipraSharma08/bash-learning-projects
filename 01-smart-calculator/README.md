# Smart Calculator

A command-line calculator built with Bash scripting.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero protection
- Repeated calculations using a loop
- Exit option
- Functions for clean and reusable code

## Technologies

- Bash
- Linux Terminal

## How to Run

Make the script executable:

chmod +x calculator.sh

Run the calculator:

./calculator.sh

## Example

===== Smart Calculator =====
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

Choose an operation (1-5): 1
Enter first number: 10
Enter second number: 5
Sum: 15
